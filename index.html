Quick Actions

⚙️ Supabase Cloud Configuration

এই রিমোট কন্ট্রোলারটি Supabase (PostgREST + Realtime) ব্যবহার করে স্ক্রিন স্ট্রিম করে।

Required Supabase SQL Table:

Supabase SQL Editor-এ এই কোড রান করুন: 

CREATE TABLE IF NOT EXISTS public.hosts (
    id TEXT PRIMARY KEY,
    password TEXT NOT NULL DEFAULT 'HostAdmin@2026',
    status TEXT NOT NULL DEFAULT 'ONLINE',
    is_screen_on BOOLEAN DEFAULT true,
    battery_pct INT DEFAULT 100,
    is_charging BOOLEAN DEFAULT false,
    streaming_mode TEXT DEFAULT 'LOW_LATENCY',
    last_heartbeat BIGINT NOT NULL,
    latest_frame TEXT,
    frame_timestamp BIGINT,
    telemetry JSONB DEFAULT '{}'::jsonb,
    webrtc_session JSONB,
    webrtc_ice_host JSONB,
    webrtc_ice_web JSONB,
    commands JSONB DEFAULT '[]'::jsonb,
    created_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now()),
    updated_at TIMESTAMPTZ DEFAULT timezone('utc'::text, now())
);
ALTER TABLE public.hosts ENABLE ROW LEVEL SECURITY;
DROP POLICY IF EXISTS "Allow public anon full access for mobile remote host" ON public.hosts;
CREATE POLICY "Allow public anon full access for mobile remote host"
    ON public.hosts FOR ALL
    TO anon, authenticated
    USING (true) WITH CHECK (true);

🕶️ Incognito / Private Tab Unblocker

Android সিস্টেমে Google Chrome এবং অন্যান্য ব্রাউজার ডিফল্টভাবে ইনকগনিটো মোডে স্ক্রিন ক্যাপচার ব্লক (Black Screen) করে রাখে।

⚡ ১-ক্লিকে ইনকগনিটো স্ক্রিন চালু করার উপায়:
  1. নিচের "Open Chrome Settings on Phone" বাটনে ক্লিক করুন।
  2. ফোনে ক্রোম খুললে "Settings (⚙️) ➔ Privacy and security"-তে যান।
  3. "Incognito screenshot" অপশনটি চালু (ON) করে দিন!
  4. ব্যাস! সাথে সাথে এই ওয়েবসাইটে ইনকগনিটো ট্যাবের লাইভ স্ক্রিন ভেসে উঠবে।
